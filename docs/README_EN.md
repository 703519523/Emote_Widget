# EmoteWidget

A fully-featured, dynamic character display component based on PySide6, designed to load and control [FreeMote (E-mote)](https://github.com/UlyssesWu/FreeMote) models (specifically those unpacked from visual novels). It provides a high-level, pure Python API that completely encapsulates all complex interactions with the underlying Web engine and JavaScript, allowing developers to easily integrate interactive 2D characters into desktop applications.

## ✨ Core Features

*   **High-Level Python SDK**: Control characters with simple, intuitive Python methods (e.g., `play()`, `set_scale()`) without writing a single line of JavaScript.
*   **Intelligent Model Loading**: Automatically introspects model variables upon loading, generating and caching parameter maps (`.map.json`) to drastically simplify the model adaptation process.
*   **Robust Animation Control**: Supports main timeline animations and overlayable differential animations (e.g., facial expressions), with controls for speed, smooth transitions, and state resets.
*   **Adaptive Lip-Sync**: Built-in lip-sync system based on a Dual Exponential Moving Average (Dual EMA) algorithm. It adapts to real-time audio streams (or files) with volume normalization, delivering fluid and natural mouth movements.
*   **Extensible Plugin System**: Automatically scans and loads all plugins in the `plugins` directory, enabling easy expansion of functionality (e.g., TTS integration, AI chat, etc.).
*   **Rich Visual Effects**: Supports transform (position/scale/rotation), global opacity, grayscale, vertex coloring, background image replacement, and more.
*   **Physics & Environment Simulation**: Adjust the physical swaying amplitude of hair and accessories, and simulate global wind effects.
*   **Built-in Interaction**: Out-of-the-box support for mouse dragging, scroll zooming, and gaze tracking.
*   **Comprehensive Testing Platform**: Includes a fully functional graphical testing tool `run_tests.py`, allowing users to explore and debug most features without writing code.

## 💻 System Requirements

*   **OS**: Windows 10/11, macOS 11+, or Modern Linux (Ubuntu 20.04+, Arch, etc.)
*   **Python**: 3.10 or higher
*   **Dependencies**: PySide6 (Qt WebEngine support required)

## 🚀 Quick Start: Using the Tester

The project comes with a powerful interactive testing platform, `run_tests.py`, which is the best way to understand and debug all features.

**1. Prepare Environment**

Ensure you have the required Python libraries installed:
```bash
pip install PySide6 numpy soundfile sounddevice
```

**2. Run the Tester**

Execute the `run_tests.py` file directly:
```bash
python run_tests.py
```

**3. Explore Features**

The testing platform (`run_tests.py`) provides a comprehensive tabbed interface:

*   **⚙️ Basic:** Dynamically load `.psb` models and backgrounds; toggle transparent window mode.
*   **↔️ Transform / 🎬 Animation / 🎨 Appearance / 💨 Physics:** Real-time sliders for scaling, rotation, speed, opacity, physics, and wind control.
*   **🔬 Binding:** Inspect runtime-introspected variables in real-time. Adjust ranges, categories, and tags, then **save to cache** for future use.
*   **🖱️ Interaction:** Test mouse dragging, zooming, gaze tracking, and audio-driven lip-syncing (from `.wav`).
*   **💡 Advanced:** Test differential animations, the dialog system, and query internal model data.
*   **🧩 Plugins:** View loaded plugins and interact with their custom UIs.
*   **💻 Console:** Built-in interactive Python console with **code autocompletion**, history, and real-time object inspection for deep debugging.

### ⚠️ A Note on Development

This project is the result of a rapid iteration process by a solo developer over the course of three weeks, evolving from concept to a feature-complete framework.

To achieve such high efficiency, this project heavily utilized **AI-assisted programming tools**. Specifically, the formatting of the Python backend, the implementation of some utility functions, and **the entire frontend HTML/JavaScript codebase** were initially generated by AI, followed by manual logic fixing, integration, and final debugging.

**Key Points:**
*   **Backend First**: The core focus of this project is to provide a powerful and developer-friendly **Python SDK (`EmoteWidget`)**.
*   **Frontend as a Demo**: As I am not primarily a frontend developer, the accompanying `pyside_webview.html` and its JavaScript code should be viewed as a **functional Proof-of-Concept**. While it successfully drives the model and demonstrates all features, the code structure may be rough (e.g., extensive use of global variables) and might contain unknown edge cases or bugs.

I am disclosing this to give all users and potential contributors a clear understanding of the project's status. Contributions of any kind are highly welcome, especially regarding refactoring, optimization, and improvements to the frontend code!

## 👨‍💻 Programmatic Usage

Integrating `EmoteWidget` into your own PySide6 application is straightforward.

```python
import sys
from PySide6.QtWidgets import QApplication, QMainWindow
from emote_widget import EmoteWidget

class MyApp(QMainWindow):
    def __init__(self):
        super().__init__()
        self.setWindowTitle("My App with EmoteWidget")
        self.resize(800, 600)

        # 1. Instantiate EmoteWidget
        self.emote_widget = EmoteWidget(self)
        self.setCentralWidget(self.emote_widget)

        # 2. Connect signals to handle logic when the page and model are ready
        self.emote_widget.load_finished.connect(self.on_page_loaded)
        self.emote_widget.player_ready.connect(self.on_player_ready)

    def on_page_loaded(self):
        """Load a model when the internal web page finishes loading"""
        print("Page loaded, loading model...")
        # Model file "chara.psb" should be placed in "web_frontend/models/"
        self.emote_widget.load_model("chara.psb")

    def on_player_ready(self, available_animations):
        """Control character behavior when the model is ready"""
        print(f"Model ready! Animations: {available_animations}")
        
        # 3. Call API to control the character
        self.emote_widget.play("idle_01")
        self.emote_widget.set_scale(0.8, duration_ms=500)

if __name__ == "__main__":
    app = QApplication(sys.argv)
    window = MyApp()
    window.show()
    sys.exit(app.exec())
```
